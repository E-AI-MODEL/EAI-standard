# Human Action Map: evidence note

**Status:** candidate evidence note
**Scope:** grounding for the Dutch Human Action Map candidate

The readable Dutch definitions are EAI synthesis, not quotations from the sources below. A source reference supports or constrains a construct; it does not imply that the exact Dutch lexical boundary is established by that publication.

This distinction matters especially for pairs such as wegen / afwegen, opmerken / signaleren and beoordelen / evalueren. Those boundaries are useful for educational precision, but should not be presented as scientific consensus about Dutch vocabulary.
