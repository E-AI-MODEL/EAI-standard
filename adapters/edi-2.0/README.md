# Expliciete Directe Instructie 2.0 adapter

Status: candidate

This adapter maps **Expliciete Directe Instructie 2.0 (EDI)** to the EAI Standard without treating EDI as equivalent to generic explicit instruction or to Direct Instruction in the Engelmann tradition.

## Source basis

Primary public sources used for this candidate adapter:

- Hollingsworth, J., & Ybarra, S. (2025). *Expliciete Directe Instructie 2.0: Tips en technieken voor een goede les* (M. Schmeier, Nederlandse bewerking). Uitgeverij Pica.
- Uitgeverij Pica public download: *Lesfasen* poster for EDI 2.0.
- Directeinstructie.nl, official training and model pages associated with Marcel Schmeier.

The public phase poster identifies nine lesson phases and four cross-cutting techniques. These are preserved as source elements in `model.yaml`.

## Important status note

The adapter is source-faithful to the publicly available EDI 2.0 materials listed above. Where the full book contains additional distinctions not present in those public materials, this adapter must not infer them. Such fields remain `unknown` until verified against an authorised source.

## EAI interpretation

EDI is especially useful for testing EAI because it contains explicit decision points around:

- activating prior knowledge;
- making the learning goal explicit;
- teacher instruction and modelling;
- guided practice;
- checking whether learners can proceed independently;
- independent practice;
- additional or deeper instruction based on learner evidence;
- closing and evaluating the lesson.

The EAI mapping keeps separate:

- what the source model says;
- what the teacher/professional is doing;
- what the learner is doing;
- what AI could do in the same process position;
- what human evidence is needed before a stronger claim is made.
